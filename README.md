# 🏓 Table Tennis Registration

Web application for registering participants to table tennis events at University Campus Bohunice, Brno.

## Features

- Registration for 4 event dates (July 29, August 12, 19, 26)
- Automatic confirmation emails via EmailJS
- Participant list with unregister functionality
- MongoDB database for global data access
- Responsive design with modern UI
- Language switching (SK/EN)

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Vercel Functions
- Database: MongoDB Atlas
- Email: EmailJS
- Hosting: Vercel

---

Built for TESCAN table tennis events in Brno.
